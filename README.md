智能电网运维系统（毕业设计）

作者：wangchangzhen

技术栈

- 后端：Spring Boot 3、Spring AI、MyBatis、MySQL  
- 前端：Vue 2、Element UI（若依 Vue 分支）  
- 其他：本地 Python 服务（风力发电预测 GRU 等）

功能概要

- 设备与多维运维数据、运行状态、告警 / 故障 / 规则联动  
- AI 对话、RAG、自然语言查库、运维表单生成与站内消息  
- 风力发电功率预测（Java 调 Python）、配置绑定与可视化
