# 智能电网运维管理系统——功能实现说明（毕业论文用稿）

**作者：** wangchangzhen

> **范围说明**：下文仅描述 **前端 `ruoyi-ui` 已存在业务页面、且通过 `src/api` 调用后端已实现接口** 的功能。不含仅有后端 Controller、无对应菜单/页面的扩展（如单独的业务模块若未做 Vue 页面则不入本文）。SQL 脚本顺序见 **`sql/README.md`**。

---

## 1 引言

本系统在 **若依 RuoYi-Vue** 前后端分离架构上扩展智能电网运维场景：设备与多维数据管理、运行状态与规则告警联动、**智能问答（Spring AI）**、**运维表单**、**站内消息**、**风力发电预测**及 **预测结果（eq_prediction）管理** 等。下列各节均标明 **前端路径 + API + 后端 Controller**，便于写论文时核对。

---

## 2 系统目标与总体架构

### 2.1 建设目标（与已实现页面对齐）

- **设备侧**：设备台账、运行状态、参数、告警、故障、维护及多维子表（机械、运行、技术、电气、经济、环境、气候等）的 **列表与维护页面** 均存在于 `ruoyi-ui/src/views/equipment/*`，对应后端 **`/equipment/*`**。
- **规则与告警**：规则配置、告警记录等与设备状态联动；后端 `EqDeviceStatusServiceImpl` 写库后触发规则评估（详见 §3.2）。
- **AI 交互**：`views/ai/chat/index.vue` 提供 **基础对话（SSE）**、**知识库问答（SSE）**、**自然语言查库（GET `/springai/db/ask`）** 及知识库维护（添加文档、清空）。
- **运维表单**：`views/ai/maintenance-form/index.vue` 调用 **`/springai/maintenance-form/*`**，完成待维护设备聚合、单台/批量生成、表单 CRUD。
- **风力预测（主线）**：`views/powerForecast/index.vue` 调用 **`windForecast.js`** → **`/wind/forecast/*`**，含按设备预测、Excel/模型上传下载、曲线与 AI 总结；同页 **「预测记录」Tab** 展示落库的 **`eq_prediction`** 与 **`eq_device_stat`**。
- **功率预测（Spring AI 路线）**：`views/ai/power-forecast/index.vue` 调用 **`api/ai/power.js`** → **`/springai/power/*`**（训练 / 推理 / 状态），与上一条为 **两套独立前后端链路**，菜单入口不同。
- **预测数据菜单页**：`views/equipment/predictionData/index.vue`（及同结构的 `prediction/index.vue`，视菜单配置选用）调用 **`api/equipment/prediction.js`** → **`/equipment/prediction/*`**，对 **`eq_prediction`** 做查询与维护。
- **站内消息**：布局组件 **`components/MessageCenter/index.vue`** 调用 **`api/system/userMessage.js`** → **`/system/user-message/*`**（列表、未读数、已读等）。

### 2.2 后端模块（与上述页面对应）

| 模块 | 职责 |
|------|------|
| `ruoyi-admin` | 启动入口；`WindForecastController`（`/wind/forecast`）、设备域各 `Eq*` Controller、`SysUserMessageController` 等 |
| `ruoyi-system` | 实体、Mapper、`Eq*` / 站内消息 / `EqWindForecastBind` 等业务服务 |
| `ruoyi-framework` | Security、JWT、Redis 封装等 |
| `ruoyi-common` | 通用组件 |
| `spring-ai` | 包根 `com.thor.springai`：`AiDeomController`（`/springai/chat`）、`RagController`（`/springai/rag`）、`DatabaseQueryController`（`/springai/db`）、`MaintenanceFormController`（`/springai/maintenance-form`）、`ChatHistoryController`（`/springai/history`）、`PowerPredictController`（`/springai/power`） |
| `ruoyi-quartz` | 定时任务；如 **`MaintenanceFormScheduleFacade`** 委托 `springAiMaintenanceFormService` |

**说明**：当前 `SecurityConfig` 对 **`/springai/**`** 配置了 **`permitAll`**（便于联调）；生产环境建议改为需登录或与若依鉴权一致。

## 3 功能模块（前后端对应）

### 3.1 设备与多维数据管理

| 前端页面（示例） | API 模块 | 后端路径前缀 |
|------------------|----------|----------------|
| `equipment/device/index.vue` | `api/equipment/device.js` | `/equipment/device` |
| `equipment/status/index.vue` | `deviceStatus.js` | `/equipment/deviceStatus` |
| `equipment/param/index.vue` | `deviceParam.js` | `/equipment/deviceParam` |
| `equipment/rule/index.vue` | `deviceRule.js` | `/equipment/deviceRule` |
| `equipment/alert/index.vue` | `alertRecord.js` | `/equipment/alertRecord` |
| `equipment/fault/index.vue` | `faultRecord.js` | `/equipment/faultRecord` |
| `equipment/maintenance/index.vue` | `maintenanceRecord.js` | `/equipment/maintenanceRecord` |
| `equipment/mechanical`～`climate` 等各子目录 `index.vue` | 同名 `*Data.js` | `/equipment/*Data` |
| `equipment/stat/index.vue` | `deviceStat.js` | `/equipment/deviceStat` |
| `equipment/manage/index.vue` | 聚合展示（依赖设备与统计数据） | 多个 `/equipment/*` |

实现要点：Controller → Service → Mapper → XML；设备删除在业务层级联清理关联数据；权限前缀多为 **`equipment:*`**。

---

### 3.2 设备规则与运行状态联动

- **后端**：`IEqDeviceRuleTriggerService`、`IEqDeviceRuleEvaluationService`（`ruoyi-system`）；`EqDeviceStatusServiceImpl` 在 **`insert` / `update` 成功** 后调用 **`evaluateAfterStatusChange`**；支持 **`reevaluateRulesByDeviceId`** 供定时任务重算。
- **前端**：通过 **设备状态**、**规则**、**告警** 等页面维护数据；无单独「规则引擎」页面，联动在 **保存状态时后台自动执行**。

---

### 3.3 智能问答、RAG、对话历史（同一页面）

- **前端**：`views/ai/chat/index.vue`；**API**：`api/ai/chat.js`。
- **基础对话**：`GET /springai/chat`，流式 **`GET /springai/chat/stream`**（SSE）。
- **知识库问答**：`GET /springai/rag/ask`，流式 **`GET /springai/rag/ask/stream`**；侧栏 **添加文档** `POST /springai/rag/document`、**清空** `POST /springai/rag/clear`。
- **数据库查询模式**：`GET /springai/db/ask`；侧栏加载统计 **`GET /springai/db/stats`**。
- **历史会话**：`GET /springai/history/list`、`GET /springai/history/{id}`、`DELETE /springai/history/delete`。

**未在前端页面使用的后端接口（不写成功能条目）**：例如 `POST /springai/db/query`、`GET /springai/db/context` 等仅在 `DatabaseQueryController` 中存在，**当前聊天页未调用**，论文若提及请标明为接口预留或运维用途。

**说明**：`api/ai/chat.js` 中的 **`generateForm`（`/springai/rag/generate-form`）** 在当前 **views 中无引用**；运维表单生成以 **`/springai/maintenance-form/*`** 为准（见 §3.5）。

---

### 3.4 运维表单业务编排

- **前端**：`views/ai/maintenance-form/index.vue`。
- **API**：`chat.js` 中 `getDevicesRequiringMaintenance`、`generateFormForDevice`、`batchGenerateForms`、`listAiMaintenanceForm`、`getAiMaintenanceFormById`、`updateMaintenanceForm`、`deleteMaintenanceForm`、`batchDeleteMaintenanceForms` → 前缀 **`/springai/maintenance-form`**。
- **后端**：`MaintenanceFormController`；核心服务 **`MaintenanceFormService`**（Bean 名 **`springAiMaintenanceFormService`**）。
- **站内信**：入库后可触发 **`ISysUserMessageService.notifyMaintenanceFormPending`**；定时扫描见 **`MaintenanceFormNotifyTask`**（可与 Redis 配合防重）。

---

### 3.5 风力发电预测（`/wind/forecast`）

- **前端**：`views/powerForecast/index.vue`；**API**：`api/windForecast.js`。
- **后端**：`WindForecastController`、`WindForecastBridgeService`、`WindForecastProperties`（含 **`bindDeviceId`**、**`persistEqPrediction`**、全局 YAML Excel 回退判断 **`isGlobalYamlFallbackDevice`** 等）。
- **页面功能**：设备选择、立即预测、刷新、AI 总结、特征/功率 Excel 与模型上传下载、曲线展示；**「预测记录」Tab** 拉取 **`eq_prediction`** 列表与 **`eq_device_stat`**，与配置 **`wind.forecast.persist-eq-prediction`** 一致。

---

### 3.6 功率预测 Spring AI 页面（`/springai/power`）

- **前端**：`views/ai/power-forecast/index.vue`。
- **API**：`api/ai/power.js` → **`POST /springai/power/train`**、**`POST /springai/power/predict`**、**`GET /springai/power/status`**。
- **后端**：`PowerPredictController`、`PowerPredictService`。

与 §3.5 **并存**：菜单与数据流独立，论文中宜分条描述，避免混为一谈。

---

### 3.7 预测结果表 `eq_prediction`（菜单 CRUD）

- **前端**：`views/equipment/predictionData/index.vue`（若菜单指向 `equipment/prediction/index.vue`，组件逻辑一致）。
- **API**：`api/equipment/prediction.js` → **`/equipment/prediction/*`**（列表、按设备、CRUD、导出等）。
- **后端**：`EqPredictionController`。

与 §3.5 **Tab「预测落库」** 使用同一批后端数据；一为 **独立菜单管理页**，一为 **预测页内嵌列表**。

---

### 3.8 站内消息中心

- **前端**：`components/MessageCenter/index.vue`（挂载于布局导航栏）。
- **API**：`api/system/userMessage.js` → **`/system/user-message/list`**、**`unreadCount`**、**`read/{msgId}`**、**`readAll`**、删除等。
- **后端**：`SysUserMessageController`、`SysUserMessageServiceImpl`；运维表单去重可与 **Redis SET NX**（`CacheConstants`）配合。

---

### 3.9 系统管理与其他（若依标配）

用户、角色、菜单、部门、字典、参数、通知、日志、定时任务、首页大屏等：**前端 `views/system`、`views/monitor`、`views/dashboard` 等与若依一致**，后端为对应 `Sys*`、`monitor/*` 接口；论文可简述「基于若依扩展」。

## 4 关键技术与数据流小结

| 技术点 | 用途 |
|--------|------|
| Spring Boot 3.2.x + Java 21 | 后端 |
| Spring Security 6 + JWT + `@PreAuthorize` | 鉴权（注意 `/springai/**` 当前匿名放行） |
| MyBatis + MySQL | 持久化 |
| Spring AI + DashScope | 对话、RAG、查库摘要、运维表单总结等 |
| SSE | 聊天页流式输出 |
| HTTP 客户端 | Java 调用 Python 风力预测服务 |
| Vue 2 + Element UI | 管理端 |

**数据流（仅列已有页面参与的链路）**

1. 前端编辑设备状态 → `/equipment/deviceStatus` → 后端规则评估 → 告警与状态回写。  
2. 聊天页提问 → `/springai/chat/stream` 或 `/springai/rag/ask/stream` 或 `/springai/db/ask` → 展示 / 落库 `ai_chat_record`。  
3. 运维表单页 → `/springai/maintenance-form/*` → 可选站内消息。  
4. 风力预测页 → `/wind/forecast` → Python → 缓存 / `eq_device_stat` / 可选 `eq_prediction`。  
5. 消息中心轮询 → `/system/user-message/*`。
